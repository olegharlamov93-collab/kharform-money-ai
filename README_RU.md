# KHARFORM MONEY AI — первый MVP

Это стартовая версия Telegram-бота для приёма заявок KHARFORM и подготовки черновиков публикаций.

## Что умеет
- Принимать сообщения от клиентов и пересылать их администратору.
- Сохранять заявки в локальную SQLite-базу.
- Позволять администратору создавать черновики публикаций командой `/newpost`.
- Показывать ожидающие черновики командой `/pending`.
- Одобрять или отклонять черновики командами `/approve ID` и `/reject ID`.
- Показывать статистику командой `/stats`.

## Чего пока НЕ умеет
Это ещё не автономный AI-агент и не система заработка «сама по себе».
Автопубликация, генерация AI-контента, поиск клиентов и интеграции с CRM пока не подключены.
Одобрение черновика только меняет его статус в базе, ничего не публикует.

## Запуск
1. Установить Python 3.10 или новее.
2. Установить зависимости: `pip install -r requirements.txt`
3. Задать переменные окружения:
   - `BOT_TOKEN` — токен от BotFather.
   - `ADMIN_ID` — Telegram ID администратора (в этом проекте указан 715454218).
4. Запустить: `python bot.py`

Токен не добавляйте в GitHub и не отправляйте в переписку. Добавляйте его только в секретные переменные окружения хостинга.

## Важно для размещения
Бот должен работать постоянно. Выбирайте хостинг, который поддерживает постоянно работающий Python-процесс и постоянное хранение файла SQLite. На хостингах с временной файловой системой база может пропадать после перезапуска.
